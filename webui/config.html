“Install CLI” runs uv tool install 'watch-skill[standard] @ git+https://github.com/oxbshw/watch-skill' (falling back to pipx) and registers the watch-skill MCP server in Agent Zero settings. The [standard] extra is required — a bare install ships no frame extraction, no retrieval and no MCP server. Use the Save button in the modal footer to persist the fields below.

Installation

The CLI is installed into an isolated tool env (uv tool, falling back to pipx) so its binary lands on PATH. There is deliberately no pip step: installing into the Agent Zero venv leaves the binary where the tools cannot find it.

Vision provider

Model used for visual Q&A and scene descriptions. Transcription, OCR and search work without one. The provider and model below are applied to each tool call as WATCHSKILL_VISION_PROVIDER / WATCHSKILL_VISION_MODEL. API keys are read from environment variables only — never stored here, and redacted from anything echoed back to the model.
